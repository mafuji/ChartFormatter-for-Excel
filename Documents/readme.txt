****************************************************************************************

	ChartFormatter for Excel

****************************************************************************************

----------------------------------------------------------------------------------------
	概要
----------------------------------------------------------------------------------------

	散布図をいい感じに整形したり、充放電サイクルのグラフを作ったりするExcelのアドインです


----------------------------------------------------------------------------------------
	インストール手順
----------------------------------------------------------------------------------------

	1. 「ChartFormatterSetup.exe」を実行
	2. 「インストール」ボタンを押下してインストール開始
	3. インストール完了後、Excelの「アドイン」タブに各種ボタンが表示されます


----------------------------------------------------------------------------------------
	アンインストール手順
----------------------------------------------------------------------------------------

	1. 「ChartFormatterSetup.exe」を実行
	2. 「アンインストール」ボタンを押下してアンインストール開始
	3. アドイン登録が解除され、xlamファイルが削除されます


----------------------------------------------------------------------------------------
	バージョンアップデート手順
----------------------------------------------------------------------------------------

	①ブラウザからインストーラをダウンロードする場合

	1. GitHubから最新バージョンの「ChartFormatter.zip」をダウンロード
	2. 解凍して「ChartFormatterSetup.exe」を実行
	3. 「アップデート」ボタンを押下してアップデート開始
	4. 完了後、アドインが最新バージョンに置き換わります


	②アドインタブの通知から更新する場合

	1. GitHubに最新バージョンがアップされると、アドインタブに
	   「ChartFormatterの新しいバージョンがあります」ボタンが表示される
	2. 上記ボタンを押下してインストーラをダウンロードし起動する
	3. 「アップデート」ボタンを押下してアップデート開始
	4. 完了後、アドインが最新バージョンに置き換わります

	Microsoft Defender SmartScreenにより、インストーラが実行出来ない場合の対処手順
	（exe実行時に青い画面等が出る場合）

	1. 「ChartFormatterSetup.exe」を右クリックしてプロパティを開く
	2. 「全般」タブ内の下部「セキュリティ」欄で「許可する」にチェック
	   ※Windowsのバージョン等により画面が異なる場合あり
