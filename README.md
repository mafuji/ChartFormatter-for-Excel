# ChartFormatter for Excel

Excelの散布図をきれいに整形したり、充放電サイクルのグラフを簡単に作成したりできるExcelアドインです。

---

## 概要

* **散布図の自動整形**: 既存の散布図をきれいに整形します。
* **充放電サイクルグラフの作成**: 充放電サイクルのデータからグラフを作成します。

---

## インストール手順

1. `ChartFormatterSetup.exe` を実行します。
2. **「インストール」** ボタンをクリックしてインストールを開始します。
3. インストール完了後、Excelの **「アドイン」** タブに各種ボタンが表示されます。

---

## アンインストール手順

1. `ChartFormatterSetup.exe` を実行します。
2. **「アンインストール」** ボタンをクリックしてアンインストールを開始します。
3. アドイン登録が解除され、xlamファイルが自動的に削除されます。

---

## バージョンアップデート手順

アップデートには、以下の2つの方法があります。

### ① ブラウザからインストーラをダウンロードする場合
1. GitHubから最新バージョンの `ChartFormatter.zip` をダウンロードします。
2. 圧縮ファイルを解凍し、`ChartFormatterSetup.exe` を実行します。
3. **「アップデート」** ボタンをクリックしてアップデートを開始します。
4. 完了後、アドインが最新バージョンに置き換わります。

### ② アドインタブの通知から更新する場合
1. GitHubに最新バージョンが公開されると、Excelの「アドイン」タブに **「ChartFormatterの新しいバージョンがあります」** というボタンが表示されます。
2. このボタンをクリックしてインストーラをダウンロードし、起動します。
3. **「アップデート」** ボタンをクリックしてアップデートを開始します。
4. 完了後、アドインが最新バージョンに置き換わります。
